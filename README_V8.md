# Afterglow v8 — Emotional Director (локальный прототип)

**Идея:** фотографии показывают, что происходило, а Afterglow помогает выразить, как это ощущалось. Это развиваемый проект для хакатона.

## Что нового в v8

- **Эмоциональная дуга истории**: текст делится на три смысловых фрагмента. Каждый фрагмент получает объяснимый эмоциональный оттенок (радость, нежность, ностальгия, грусть, напряжение, покой, драйв, надежда). Пролог и эпилог формируют фильм из пяти сцен.
- **Интерактивный Storyboard** под фильмом: можно нажать на эмоцию, перейти к сцене и увидеть объяснение выбора.
- **Цвет, композиция и длительность кадров** теперь меняются по ходу одной истории. Одинаковые фотографии с разными историями могут давать разные результаты.
- **Экспорт WebM** учитывает ритм эмоциональной дуги. При наличии загруженного аудиофайла музыка включается в экспорт.
- Исправлен выбор песни: новый день не наследует скрыто выбранную композицию предыдущего дня. Обновлена очистка временных URL фотографий.
- Сохранились: до 12 фотографий, 3 арт-стиля, монтажная, редактирование кадров и надписей, локальный архив, экспорт постера PNG и перенос дня через JSON.

## Запуск (Windows, Chrome или Edge)

1. **Распакуй ZIP полностью.** Открой папку `afterglow-v8`.
2. Самый простой вариант — открыть `index.html` двойным щелчком. Интернет для локального арт-директора не нужен.
3. Если браузер блокирует часть функций при открытии файла, открой папку в VS Code и запусти `index.html` через расширение Live Server.
4. Нажми **Новый день**, напиши текст от 15 символов, добавь минимум одну фотографию. Музыка необязательна, но для звука в экспорте добавь свой локальный аудиофайл.
5. Создай фильм, попробуй нажать на разные эмоции в Storyboard, нажми **Смотреть со звуком**, если загружена музыка.
6. Внизу есть **Режиссёрская монтажная**: редактируй и сохраняй сцены, экспортируй постер, фильм WebM или файл дня JSON.

## Что стоит знать

- Без сервера и Gemini API анализ **эвристический, а не нейросетевой**, и не является психологической диагностикой. Веб-поиск песни через iTunes требует интернета, доступен 30-секундный фрагмент (если сервер и браузер разрешат загрузку).
- Музыка **по ссылке** из Spotify или YouTube не включается автоматически в экспорт (так устроены ограничения платформ и права на контент). Надёжный вариант — использовать собственный разрешённый аудиофайл.
- Архив хранится в локальном IndexedDB выбранного браузера. Для резервной копии экспортируй `.json`.
- WebM экспортируется в Chrome/Edge в реальном времени. Вкладка должна оставаться открытой. На некоторых устройствах может не работать; проверь до презентации.
- Один фильм пока состоит из **5 сцен**. Количество фото — до 12, фотографии распределяются между сценами, а их выбор можно изменить в монтажной.

## Структура

`index.html` — интерфейс. `app.js` — создание, плеер, сохранение. `arc.js` — эмоциональный режиссёр. `arc.css` — Storyboard и оттенки сцен. `studio.js` — редактор и экспорт. `director.js` — глобальный художественный профиль. Остальные файлы — стили и дополнительные функции.

## Контрольный список для демонстрации

1. Протестировать создание нового воспоминания с 3–5 фотографиями и **своим** аудиофайлом.
2. Нажать **Смотреть со звуком** и убедиться, что он реально играет.
3. Поменять фотографию и текст одной сцены, нажать **Сохранить монтаж**, открыть запись из архива снова.
4. Скачать постер PNG и видео WebM; убедиться, что файл видео воспроизводится и в нём есть звук.
5. Экспортировать файл дня JSON и импортировать обратно через архив.
