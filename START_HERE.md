# Afterglow v9 — быстрый запуск

1. Распакуй ZIP целиком, открой папку `afterglow-v9`.
2. Открой `index.html` в Chrome или Edge. Если браузер блокирует отдельные возможности, открой папку в VS Code и запусти через Live Server.
3. На главной можно нажать кнопку демо — она заполнит пример текста и фото. Затем нажми «Создать воспоминание».
4. Для собственного воспоминания добавь текст (от 15 символов), 1–12 фотографий и, при желании, локальный аудиофайл.
5. В монтажной можно менять порядок фотографий, подписи, тему, длительность и формат видео (16:9, 9:16, 1:1). Сохрани изменения.
6. Экспортируй постер PNG, фильм WebM и резервную копию JSON. Не закрывай вкладку во время экспорта.

## Важно

- Локальный эмоциональный анализ — алгоритм, **не нейросеть**. Настоящий Gemini-анализ требует настроенного сервера/API-ключа.
- Музыка из ссылок YouTube/Spotify не встраивается в экспорт. Для видео со звуком загружай собственный аудиофайл, на использование которого у тебя есть права.
- WebM записывается в реальном времени, поэтому длинное видео экспортируется не мгновенно. MP4 пока не реализован.
- Воспоминания сохраняются локально в браузере. Для переноса на другой компьютер используй JSON.
- Перед выступлением обязательно проверь экспорт WebM **со звуком** на компьютере, с которого будете показывать проект.

## Обновление v9.1 — текст и поиск музыки
- Подписи глав теперь идут строго в порядке исходного рассказа: предложения не перемешиваются и не повторяются, даже если фотографий больше, чем предложений.
- Пролог и эпилог показывают название воспоминания. Порядок фотографий можно менять независимо от порядка текста.
- Поиск музыки проверяет каталоги Apple Music для US, JP, KZ, GB и RU и ранжирует совпадения по исполнителю и названию.
- Не все песни присутствуют в каталоге Apple Music и не у всех есть доступный фрагмент. Для гарантированного звука и экспорта добавь собственный аудиофайл.
- Для онлайн-поиска необходим интернет. Если запускаешь сайт с file:// и поиск блокируется браузером, открой через Live Server.
