# Тесты для команды перед сдачей

Проверь на компьютере участника, который будет записывать демонстрацию.

[ ] Сайт открывается в Chrome/Edge через `index.html` и из простого локального сервера.
[ ] Ввод текста меняет эмоциональные оси в блоке MOOD ENGINE.
[ ] Фото влияет на цветовую палитру; создание без фото заблокировано.
[ ] Создание без ссылки/аудиофайла заблокировано.
[ ] Загруженный аудиофайл воспроизводится через «Смотреть со звуком».
[ ] Ссылка YouTube/Spotify открывается в плеере, музыка запускается вручную.
[ ] Пять сцен переключаются, пауза и продолжение работают.
[ ] В монтажной изменённый стиль и текст сцены сохраняются после закрытия и повторного открытия дня.
[ ] Пробуется не менее трёх сочетаний текста/фото/музыки с видимо разными результатами.
[ ] Постер PNG скачивается и открывается в просмотрщике изображений.
[ ] Видео WebM скачивается, длится ~15–25 секунд, не имеет чёрных провалов. С собственным аудиофайлом звук внутри видео есть.
[ ] Экспорт JSON и импорт в другом браузере восстановили фотографии и аудио.
[ ] Фильтры и поиск в архиве работают.
[ ] Продуманы исходные материалы и их права; ни один чужой голос или песня не распространяется без прав.

**Если не работает экспорт WebM:** открыть Chrome/Edge; если браузер всё равно отказывает — записать демонстрацию экрана через OBS и не заявлять поддержку экспорта в итоговом отчёте.
