# Afterglow FINAL — Cinema Studio

Afterglow превращает историю и фотографии в эмоционально оформленный фильм. Работает локально в Chrome/Edge, без обязательного API.

## Что нового в v9

- Количество сцен зависит от числа фотографий: 1–12 глав плюс пролог и эпилог.
- Общий canvas-рендерер `cinema.js` для предпросмотра и экспорта WebM.
- Движение кадра, коллажные композиции, цветовые акценты и типографика в зависимости от локального анализа истории.
- Монтажная: порядок фотографий, редактирование подписей, выбор стиля, длительности и формата 16:9 / 9:16 / 1:1.
- Лёгкая синхронизация смены сцен с изменениями громкости, если удалось проанализировать загруженное аудио; **не полноценный beat detection**.
- Экспорт PNG-постера, WebM (со звуком для декодируемого локального аудио) и JSON-резервной копии.
- Пример воспоминания на главной для демонстрации.

## Запуск

См. `START_HERE.md`. Для стабильного музыкального поиска запускай `python server.py`, а не открывай файл напрямую. 

Резервный поиск работает через серверный `/api/music`; в Vercel для него есть `api/music.mjs`.

## Ограничения

- Эмоциональный анализ без API эвристический; Gemini требует отдельной серверной настройки.
- MP4, 3D-параллакс и интерактивная вселенная воспоминаний не реализованы.
- Экспорт идёт в реальном времени и зависит от поддержки MediaRecorder браузером.
- Данные хранятся в IndexedDB локального браузера. Сохраняй резервные копии JSON.
- Ссылки на коммерческие музыкальные платформы не дают права и технической возможности включать полные треки в экспорт.

### Исправление надписей в фильме

Подписи идут по порядку исходной истории без повторов. Пролог не дублирует начало текста, эпилог не повторяет название; старые сохранённые фильмы автоматически отображаются без повторяющихся подписей. Для уникальной финальной подписи отредактируйте поле «Надпись» в монтажной. Оригинальные истории и фото не изменяются.
